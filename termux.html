📱 小米钱包自动领会员

照着做一遍，之后全自动。装完不用再管，结果每天推到你钉钉。

跑通之后是什么样
  • 不用开 Termux，不用挂后台
  • 系统每天自动唤醒脚本领会员时长
  • 领完自动往你的钉钉群发一条日报
  • 耗电几乎为零
复制命令时注意：只复制命令本身，不要把 ~ $ 一起复制（那是终端提示符，不是命令）。

1 安装 Termux 33.5MB · 只需一次

⬇ 下载 Termux
点击没反应？长按按钮 → 复制链接 → 粘到浏览器地址栏打开。
安装时提示「未知来源」→ 允许一次。

2 装运行环境 几分钟

打开 Termux，等它自己下载基础包，出现 $ 后再粘命令。

pkg update -y && pkg install -y python cronie termux-api && pip install requests qrcode
中途问 Y/N 一律回车。跑完回到 $ 就好。

3 下载脚本

curl -sSL -H "Cache-Control: no-cache" -o xmwallet.py "http://hnvip.qd.je/xmwallet.py?v=$(date +%s)"
带时间戳是为了绕开缓存，保证拿到最新版。
下完敲 ls 能看到 xmwallet.py。
curl 失败的话：直接下载脚本文件，再用 cp /sdcard/Download/xmwallet.py ~/xmwallet.py （先跑 termux-setup-storage 授权）

4 扫码登录 只需一次

python3 xmwallet.py login 我的号
屏幕出二维码 → 用小米手机自带的「扫一扫」扫 → 点【允许登录】。
二维码扫不了？命令下面会跟一行 https 链接，长按复制到浏览器打开授权，一样。
✔ 看到「登录成功」就成了。

5 验证 + 手动跑一次

python3 xmwallet.py status

能看到「会员时长 105.78 天」就通了。然后：

python3 xmwallet.py run
显示「今日领取 0 笔」不是坏了 —— 说明今天已经领过了（状态 code=3），明天会自动再领。

6 装 Termux:API 全自动的关键

第 2 步的 pkg install termux-api 只装了命令行工具，真正干活的 App 要单独装。不装这一步，定时永远注册不上。

⬇ 下载 Termux:API（8.4MB）
同域名，一定能下。装完不用打开它。

7 注册全自动定时任务

python3 xmwallet.py job --cancel python3 xmwallet.py job
第一条先清掉之前重复注册的，第二条重新登记。
成功会显示 调度返回: response 1（成功）。
python3 xmwallet.py job --list
显示「已注册 1 条，周期 24 小时」就干净了。
改周期：python3 xmwallet.py job 12h

8 钉钉推送 自动生成命令

把你的机器人信息粘进去，下面会自动生成一条命令，复制后到 Termux 执行即可。

页面不保存、不上传任何输入，刷新即清空。信息只在你手机浏览器内存里，用来拼命令。
（填入上面信息后自动生成）
粘到 Termux 执行，会自动发一条测试消息到群里，收到就通了。
之后每次跑完自动推日报。
怎么拿这两个值？
钉钉群 → 右上角群设置 → 智能群助手 → 添加机器人 → 选自定义
安全设置推荐选「加签」，复制 Webhook 地址和 SEC 开头的密钥。

用关键词方式的话，密钥留空，命令里加 --keyword 小米钱包。
Webhook 等于往你群里发消息的权限，别发给别人、别贴到公开地方。
用完若担心泄露，去钉钉群 → 群设置 → 智能群助手 → 点机器人 → 重新生成 Webhook（旧的立刻失效）。

9 小米手机必做：放开后台

MIUI / 澎湃OS 会偷偷冻结 App，不设置的话任务到点叫不醒。

设置项改成
自启动开启
电池优化 / 省电策略无限制
后台运行权限允许
多任务界面下拉锁住
Termux 和 Termux:API 两个都要设，其中 Termux:API 最关键。
路径：设置 → 应用设置 → 应用管理 → 找到对应 App。

? 出问题这样查

现象怎么办
命令报 invalid choice脚本是旧版，重跑第 3 步下载
job 注册失败跑 python3 xmwallet.py job --diag，它会直接说原因
会员时长「未知」接口偶发抽风，已自动重试；跑 debug 可看原文
钉钉收不到看输出的 errcode：310000=密钥错，130101=机器人被停用
两天后不自动跑了国产 ROM 后台限制，回到第 9 步检查；仍不行就每天开一次 Termux 触发钩子
钩子方案（每天开一次 Termux 才跑，最省电）：
python3 xmwallet.py hook 移除：python3 xmwallet.py hook --remove
