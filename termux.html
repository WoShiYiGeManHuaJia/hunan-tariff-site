📦 Termux 安装 + 小米钱包脚本

按顺序做，每步点一下就行。命令都带「复制」，复制后到 Termux 里长按粘贴。

1 下载 Termux（33MB）

和本页面同一个域名，点击即可下载。装不上再试备用按钮。

⬇ 下载 Termux（推荐） ⬇ 备用下载（github.io）
下载完点开安装包 → 提示「未知来源」→ 允许一次 → 安装。
点击没反应？长按上面按钮 → 选「复制链接」→ 粘到浏览器地址栏打开。

2 打开 Termux，装环境

第一次打开会下载基础包，等它跑完出现 $ 再粘命令。

pkg update -y && pkg install -y python cronie termux-api && pip install requests qrcode
中间问 Y/N 一律回车默认。跑完回到 $ 就是好了。cronie / termux-api 装不上也没关系，只是不能定时。

3 下载脚本

走你自己的域名，不碰 GitHub。

curl -sSL -o xmwallet.py http://hnvip.qd.je/xmwallet.py
下完敲 ls 看有没有 xmwallet.py。
curl 要是还报错，用下面这个按钮直接把脚本存成文件再传进去：
⬇ 备用：直接下载脚本文件
下载后一般在「下载」目录。用 Termux 执行 cp /sdcard/Download/xmwallet.py ~/xmwallet.py 若提示找不到，先执行 termux-setup-storage 并允许权限。

4 扫码登录（只做一次）

python3 xmwallet.py login 我的号
屏幕会出一个二维码 → 用小米手机自带的「扫一扫」扫 → 手机上点【允许登录】。
二维码扫不了？命令下面会跟一行 https 开头的链接，长按复制到手机浏览器打开授权，效果一样。
✔ 看到「登录成功」就成了。

5 验证 + 跑一次

python3 xmwallet.py status

能显示「会员时长 XX 天」就通了。然后：

python3 xmwallet.py run

6 挂每天自动跑（省电，推荐）

用系统级 JobScheduler，不常驻后台进程，重启后自动恢复。

pkg install -y termux-api python3 xmwallet.py job
想改周期：python3 xmwallet.py job 12h（也支持 90m、2d）
查看已注册：python3 xmwallet.py job --list
取消任务：python3 xmwallet.py job --cancel
如果之前用过 cron，先撤销费电的那个：
pkill crond; crontab -r
⚠️ 两句实话
· 这个脚本没法提前验证「能不能真领到会员」，必须你真实账号扫了码才知道。
· 小米随时可能改接口校验，届时跑完把 xmwallet.log 发我，我照着改。
· passToken 等于账号凭证，不要外传。
