📦 Termux 安装 + 小米钱包脚本

按顺序做，每步点一下就行。命令都带「复制」，复制后到 Termux 里长按粘贴。

1 下载 Termux（33MB）

绝大多数手机点第一个。装不上再试第二个。

⬇ 下载 Termux（arm64，推荐） ⬇ 通用版（112MB，装不上再用）
下载完点开安装包 → 系统提示「未知来源」→ 允许一次 → 安装。
若提示「无法安装」，先去 F-Droid 装：f-droid.org/packages/com.termux

2 打开 Termux，装环境

第一次打开会下载基础包，等它跑完出现 $ 再粘命令。

pkg update -y && pkg install -y python cronie termux-api && pip install requests qrcode
中间问 Y/N 一律回车默认。跑完回到 $ 就是好了。cronie / termux-api 装不上也没关系，只是不能定时。

3 下载脚本

curl -sSL -o xmwallet.py https://cdn.jsdelivr.net/gh/WoShiYiGeManHuaJia/xmwallet@main/xmwallet.py
如果卡住或报错，换成这条：
curl -sSL -o xmwallet.py https://raw.githubusercontent.com/WoShiYiGeManHuaJia/xmwallet/main/xmwallet.py

4 扫码登录（只做一次）

python3 xmwallet.py login 我的号
屏幕会出一个二维码 → 用小米手机自带的「扫一扫」扫 → 手机上点【允许登录】。
二维码扫不了？命令下面会跟一行 https 开头的链接，长按复制到手机浏览器打开授权，效果一样。
✔ 看到「登录成功」就成了。

5 验证 + 跑一次

python3 xmwallet.py status

能显示「会员时长 XX 天」就通了。然后：

python3 xmwallet.py run

6 挂每天自动跑（可选）

python3 xmwallet.py cron && crond
Termux 被系统杀掉定时任务就不跑了，想稳一点可以在手机设置里把 Termux 设为「允许后台运行 / 锁定后台」。
⚠️ 两句实话
· 这个脚本没法提前验证「能不能真领到会员」，必须你真实账号扫了码才知道。
· 小米随时可能改接口校验，届时跑完把 xmwallet.log 发我，我照着改。
· passToken 等于账号凭证，不要外传。
