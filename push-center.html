关于定时推送：浏览器关闭后无法主动推送，这是所有网页的安全机制，任何页面都做不到。
因此本页负责「配置 + 测试」，定时推送由导出的配置交给常开设备执行，三条路任选：
① 自己的电脑 / 服务器 / 路由器跑脚本，读 .env 定时推送（密钥完全不出本机）；
② fork 项目后填 GitHub Actions 的 Secrets，由云端定时跑（Secrets 加密只写不读）；
③ 只用本页手动「发送测试」随时推一次。
