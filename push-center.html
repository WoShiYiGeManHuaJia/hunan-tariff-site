定时推送 · 选一种方式
第 1 步 · 复制下面整行，粘贴到终端，按回车
电脑、服务器、路由器都行。它会自动下载脚本、写好配置，并发一条测试消息。密钥只写进你自己的设备。
看到「配置成功」就通了。群里应该收到一条测试消息。
第 2 步 · 想每天自动推？选一个时间（可选）
同样粘贴到终端回车即可，会自动加到 crontab，不会覆盖你已有的定时任务。
第 1 步 · 先 fork 仓库
打开 资费监控仓库 → 右上角 Fork。之后所有配置都填在你自己的仓库里。
第 2 步 · 一键填好密钥（推荐）
如果装了 GitHub 官方命令行 gh，把下面整段粘到终端回车，所有密钥一次性填完，不用在网页上一个一个点。
没有 gh？点「手动填」，按清单在仓库 Settings → Secrets 里逐个添加。
第 3 步 · 开启自动推送
进你 fork 的仓库 → Actions → 左侧选「Tariff Notify」→ 点 Enable workflow。之后按仓库设定的时间自动跑。
不做定时推送。需要时回到上面渠道区，点「发送测试」手动推一次。
配置仍保存在本机，随时可改成上面两种方式。
数据管理（全部本地）
为什么网页自己不能定时推送：浏览器关掉就没法主动发消息，这是所有网页的安全机制，装成 App、打包成 APK 也绕不过。所以定时那一步交给上面选中的方式，本页负责「配置 + 测试」。
