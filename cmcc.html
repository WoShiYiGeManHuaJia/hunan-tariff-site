中国移动每日签到

两步搞定：先手动签一次，再把凭证交给服务器自动签
为什么一直签不上？
自动签到跑在 GitHub 的服务器上，而 GitHub 服务器在境外（实测出口 IP：美国圣何塞）。移动对境外 IP 拒绝登录，所以签不了。

你的手机在国内 —— 让签到用你手机的登录凭证就能正常签。

1打开活动页并确认已登录

  1. 用手机浏览器（Safari / Chrome）打开活动页
  2. 确认页面正常显示、右上角是你自己的号
  3. 停留在这个页面，下面的操作都在这页上做

2添加「签到书签」（今天先手动签）

  1. 点「复制书签代码」
  2. 浏览器新建书签，名字写「签到」
  3. 网址栏清空，粘贴代码，保存
  4. 回到活动页，点一下这个书签 → 弹「签到成功」

3导出凭证（关键，做完就全自动）

上一步签到成功后，你的活动页就有了登录凭证。把它导出交给服务器，服务器每天替你签，你再也不用管。
  1. 再新建一个书签，名字写「导出」
  2. 点「复制导出代码」，网址栏清空粘贴，保存
  3. 回到活动页，点一下「导出」书签
  4. 页面会弹出一串文字 → 复制 → 发给 AI

常见问题

凭证会过期吗？
会（通常几天到几十天）。过期后服务器会通知你，重复第 3 步再导一次即可。

凭证里有我的手机号吗？
没有明文号码，是会话票据。不放心可以随时在移动 App 里退出登录让它失效。
