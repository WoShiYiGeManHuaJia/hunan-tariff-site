关于本页

本页面展示中国移动「全网资费」及各省（默认湖南）的公开资费资料，数据由自动监控程序定期抓取官网并存入代码仓库，再发布为静态网页。

  • 数据来源：中国移动官网公开资费专区（湖南 + 全国，31 省可选）
  • 页面版本：2026-09-27（看到这一行说明是最新版；看不到就是手机缓存，请清缓存或用无痕模式打开）
  • 省份切换：「省份资费」页可自助选择其他省份，默认湖南；变化历史同样按省份标注
  • 更新方式：自动定时抓取比对，有变化即刷新本页
  • 数据口径：以官网「适用地区」「适用范围」字段为准，仅供参考
  • 运营商：顶部可切换运营商主题，目前仅中国移动已接入抓取数据
  • 免责声明：展示内容可能存在延迟或误差，办理业务请以营业厅 / 官方客服信息为准

开启一键抓取

填入一个对本仓库有 Actions 读写 权限的 GitHub 令牌，之后点「立即触发抓取」即可直接启动云端抓取，跑完自动刷新页面。
令牌只保存在你本机浏览器，不会写进仓库、不会上传到任何地方。
  • 创建：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → 只选本仓库 → Actions 设为 Read and write
  • 不想配置也可以点「打开 Actions 页」手动运行，效果一样
