# 中国移动资费监控 · 数据展示站

本仓库为 **Hunan-Mobile-Billing-Monitoring（私有监控仓）** 的**公开数据展示层**，仅包含从中国移动官网抓取的资费公开数据与静态展示页面，不含任何代码密钥。

- 数据：全网资费（全国）+ 湖南资费（14 地市），含套餐 / 加装包 / 营销活动 × 个人 / 政企 全分类
- 更新：由私有监控仓库的 GitHub Actions 定时抓取并自动同步到本仓库
- 数据均为中国移动官网公示的公开信息

在线访问：`https://jiangzhongming2005-byte.github.io/hunan-tariff-site/`
